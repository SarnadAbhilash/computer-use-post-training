# Examples

Two short recordings of the same locked NameError debugging task (`x4_nameerror_has_digit`).

`before_sft_v2_nameerror_fail.mp4` is the earlier fine-tuned model failing the task. `after_grpo_nameerror_success.mp4` is the GRPO model succeeding on it.

`before-after.mp4` is a short sped-up cut of both recordings, labeled before and after.
`before.gif` and `after.gif` are short clips from the end of each recording, for the write-up.
