# Results

These are the final Stage 4 evaluation numbers, completed on 2026-11-05.

`results.md` has the full tables. `overall.png` compares models on both locked test sets. `debug_by_type.png` breaks the 35 debugging tasks into the 7 bug types.

Each model was run 3 times at temperature 0.2. Scores are means over those runs. A false "done" claim means the model said it finished, but the automatic checker said the task was still wrong.
